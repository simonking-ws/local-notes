## 简介

**素笺**（仓库名 `local-notes`）是一个致敬 Apple Notes（macOS 笔记）的桌面笔记程序。它采用经典的三栏布局——顶部工具栏、左侧文件夹与笔记列表、右侧富文本编辑器，风格简洁克制，专注于「打开就能写」的流畅体验。

与大多数笔记软件不同，素笺**不依赖任何第三方库，也不连接任何云端服务**——只需要电脑上自带的 Python 即可运行。所有文件夹、笔记和设置都保存在本地的 SQLite 数据库中，配合一键导出备份（默认压缩的 `.json.gz`，也可存成可读的 `.json`），**数据的所有权完全归你自己**。

## 功能特性

**编辑与排版**
- 三栏式布局：工具栏 / 文件夹 + 笔记列表 / 编辑器，还原 macOS 笔记的交互逻辑
- **两栏可拖宽**：文件夹栏与笔记列表之间那两条竖线都能按住左右拖，宽度**实时**跟着走；
  指针压上去会变成左右箭头、细线染上主题色，**双击恢复默认**（216 / 300）。宽度按像素记进
  设置，下次启动还在。窗口变窄时会自动夹紧（文件夹最少 150、列表最少 180、正文至少留 320），
  但**不改写你的设置** —— 窗口再拉宽，列宽原样回来
- **整行操作**：`Ctrl+D` 复制光标所在行（连同加粗 / 标题 / 引用 / 待办勾选状态一并复制），
  `Ctrl+Y` 删掉整行；拖选了几行就对这几行生效
- 富文本编辑：**加粗**、*斜体*、下划线、~~删除线~~（支持 `Ctrl+B` / `Ctrl+I` / `Ctrl+U` 快捷键）
- 段落样式：H1 一级标题、H2 二级标题（点工具栏的 `H` 切换，或 `Ctrl+1` / `Ctrl+2` / `Ctrl+0`）
- **第一行恒为标题**：笔记的第一行始终是一级标题样式 —— 在首行输入的任何内容都自动套用标题，
  `## `、`> ` 等前缀和 H2/引用按钮落到第一行也一律按标题处理；首行回车后，新行恢复正文样式。
  **第一行不能加列表项**：项目符号 / 有序 / 三角 / 待办四个按钮在首行点了会提示，`- `、`1. `、
  `-> `、`-[] ` 在首行也不转换（列表是「一个符号领一整句」的行级结构，挂到 H1 底下既不好看也理不清层级）
- 列表：无序列表（●）、有序列表（1. 2. 3.）、三角形项目符号、待办勾选框；四种都相对正文右移两格
  （一个汉字宽），缩进是标记的一部分，回车续接、整行删除都不会走样；**标记与正文之间一律隔两个
  空格的位置**，所以按钮插的、markdown 敲的、回车续接出来的，四种列表看起来一般齐；**一行太长
  自动折行时，续行与正文首字对齐**（悬挂缩进），标记留在左边凸出
- 待办清单（✅ checkbox）：一键勾选，回车自动续写下一项；折行后同样与正文首字对齐。
  勾选框是**正文里的一个字符**（⬜ 未勾 / ✅ 已勾），不是浮在文字上的控件 —— 所以文字再长，
  框和文字也不会被拆到两行（框是文字流的一部分，跟后面的字同属一个不可断的词），
  能选中复制、能撤销、跟着导出一起走；鼠标移到待办这一行（含文字）变成小手，点了就勾
- 引用块、行内代码、分割线：引用是**主题色的淡色纸片** + 上下留白 + 文字缩进两格（与列表同一套标尺），
  底色铺满整行宽度，连续多行连成一块；行内代码用等宽字体 + **中性灰**底（不带主题色）——
  一有色、一中性，再加上「选中」的深色强调块，正文里三种浅色块各有各的身份，不会撞色；
  **回车续接引用**，把一行引用文字删光即退出引用（空行不再留色块）；
  分割线是一条跟随编辑区宽度的横线
- **超链接**：段中敲 `[显示文字](网址)` 再打一个空格，括号和网址当场收起来、只剩显示文字，
  文字变成蓝色 + 蓝色下划线。**指针在链接上停一下就浮出小窗**，里面是「显示文字」和「链接地址」
  两栏，都能直接改（清空地址后回车即取消链接，显示文字留空表示不改）。裸网址打完空格同样自动变蓝，
  悬停它也能改显示文字（一改就升级成「文字与地址分开存」的富链接），两种链接观感一致；
  单击链接用系统浏览器打开，链接文字和普通文字一样能选中、能改、能删，不是「隐藏起来的语法」
- **@ 关联笔记**：正文里敲 `@` + 空格，光标下方浮出候选面板（最近修改优先，带所属文件夹），
  继续打字即过滤，↑↓ 选择、Enter 插入、Esc 取消，也能鼠标点击。选中后插入蓝色的 `@标题`，
  **单击它直接跳到那篇笔记**（在别的文件夹就一并切过去）。链接存的是笔记 id 而不是标题：
  目标改名、挪文件夹都不会断链；目标被删了，点击会提示而不是静默失败。候选里不列当前笔记
  和还没解锁的加密笔记
- **多标签页**：点列表里的笔记就开成一枚标签，已经开着的那篇会**切回去**而不是再开一份；
  标签带 ×（中键单击也能关），右键可「关闭其它」，`Ctrl+W` 关当前、`Ctrl+Tab` /
  `Ctrl+Shift+Tab` 来回切换。编辑器始终只有一份正文，切标签 = 存住这篇、装下一篇，
  所以撤销栈不跨标签保留；开着的标签随设置持久化，重启后还在。标签条在工具栏下方，
  标签多了横向滚动（两端浮出箭头），最右边的 `+` 直接新建笔记
- **时间函数**：`date()` + 空格 → `2026-10-23`，`datetime()` + 空格 → `2026-10-23 19:13:05`。
  只在行尾敲完空格/回车那一刻展开一次，写进正文后就不会自己变，等于一个「立刻取当前时间」的快捷输入
- **公式计算**：`$` 起头的算式，敲完 `=` 再敲空格就补上结果 —— `$5+6=` ␣ → `5+6= 11`。
  `$` 只是「我要算」的触发键，**算完即删掉**，留在正文里的只有算式和结果，复制出去很干净；
  删掉后这行也不再是公式，再敲空格不会二次求值。支持 `+ - * /`、括号、`^` 幂、`%` 取模、
  `sin/cos/tan`（参数按**度**，可写 `tan30` 或 `tan(30)`），
  全角 `＋ × ÷ （）` 也认；结果最多两位小数（四舍五入）。**必须是 `$` 起头**才计算，
  正文里写 `5+6=` 不动；`$` 后跟汉字或字母（`$合计=`、`$x^2=`）也一律当普通文字，
  给 markdown 的 `$…$` 数学写法留了后路；算不出来（除零、`tan90`、语法不通）就静默不补值、
  `$` 也原样留着。结果是**纯文本**，不挂任何隐藏标记，导出、搜索、加密都不受影响；
  删 `$` 与补结果是同一个撤销单元，一次 `Ctrl+Z` 全部退回
- **任务提醒**：工具栏那枚小闹钟，点开填「提醒什么 + 什么时候」，正文里就多一枚 16px
  的闹钟图（图来自 `icon/notice.png`）。鼠标停上去显示时间与内容，响过之后显示「已提醒」；
  右键可编辑或删除，**删掉图标就等于取消这条提醒**。到点时右下角浮出一张置顶小卡片。
  时间用**时/分选择框**（上下箭头或直接键入，范围锁死 0-23 / 0-59，旁边有「现在」），
  日期用**日历**（点格子选日，`‹ ›` 翻月，右上角「今天」一键跳回，今天那格用强调色标出），
  都不用再手打；不勾「到点提醒」就只是正文里一个标记，永远不响（此时日历和时分一起变灰）。
  ⚠️ 两种「不响」是设计好的：**程序关着的时候不会提醒**；关着的这段时间里错过的，
  超过 10 分钟就不再补弹（只在下次悬停时显示已提醒），免得开机一次弹一串窗口
- **底部状态条**：指针挪到编辑区**底部**那一带才浮出「创建时间 · 最后修改时间 · 字数」，
  移开即收起。它贴在正文下边缘、正好占住正文的下留白，不遮挡任何一行；加密未解锁时
  这里显示「已加密 · 未解锁」
- **markdown 快捷输入**：段首敲 `# ` / `## ` / `- ` / `1. ` / `> ` / `-[] ` / `-> ` / 三个反引号，
  再敲一个空格，就地变成对应格式；三个反引号后带语言名（如 ```` ```python ````）敲回车同样直接生成代码块；
  `---` 敲完回车变分割线。结果只留样式，正文里不会残留 markdown 符号，一次 `Ctrl+Z` 就能整段撤回
- 文字颜色与下划线颜色可自选，样式随笔记一起保存、重开精确还原
- **字号只在设置里改**：滑杆调的是正文大小，H1 / H2 按比例（1.35 / 1.15）跟着缩放 ——
  正文 12 号时是 16 / 14 号，正文 20 号时是 27 / 23 号，层级不会因为放大正文而塌掉
- 正文字体也可换（默认 / 雅黑 / 黑体 / 宋体 / 楷体 / Consolas），即时全局生效并持久保存
- **导出单篇笔记**（工具栏「⋯」菜单）：纯文本 `.txt` / Markdown `.md` / PDF `.pdf` 三选一，
  文件名默认取笔记标题；只读的示例笔记也能导。PDF 是 A4 排版、用系统字体现画的
  （见下方「关于 PDF 导出」），文字不可选中，换来的是零依赖
- 工具栏可**折叠**（省下 31px 高度）与**自定义**：在顶栏齿轮的「全局设置 → 工具栏按钮」里勾选
  要显示哪几枚，十二项一格不差地列出来，右侧「全选 / 全不选」一键清空再挑；
  ⋯ 菜单不可隐藏（导出、折叠工具栏等入口在里面），配置随设置一起保存
- 工具条视觉：底色取侧栏与稿纸之间的浅色，形成「侧栏 → 工具带 → 白稿纸」的渐次提亮，
  靠底部收口线收边；按钮常态与底同色（无框无底），悬停/按下只压明度不改色相，任何皮肤下都不会串色
- 内置的「欢迎使用素笺」是**只读**的：不能编辑、不能删除，正文里列着全部快捷键。
  打开它时编辑区上方会出现一条提示条，工具栏会整体置灰；文字仍可选中复制

**代码块**
- 内置代码块：顶部语言条可随时切换语言，等宽字体 + 轻量语法高亮
- 支持语言：纯文本、JSON、XML、HTML、Java、Python、Bash、SQL
- 一键**复制**、一键**格式化**：
  - JSON / HTML / XML —— 结构化重排，按括号与标签层级缩进
  - **SQL —— 按关键词断行**：`SELECT` 之后另起一行，**每个字段各占一行**并退四格，
    `FROM` 自己占一行，`WHERE` / `AND` / `OR` / `GROUP BY` / `ORDER BY` / `JOIN` /
    `UNION` … 之前断开，一行里挤三个 AND 的长句会被摊成一行一个条件；括号内
    （子查询、`IN (…)`、函数参数、`GROUP BY` 的字段串）不动，字符串里的 `AND` 也不动。
    除下面那条中文标点归一化外，只重排空白（大小写原样）
  - Java / Bash / Python —— 重排行首缩进
- 格式化前先**统一中文标点**（仅 JSON / SQL）：中文输入法下敲出来的全角逗号 `，` 与中文引号
  `“”` / `‘’` 会先换成英文的 `,` / `"` / `'`，**JSON 另含中文冒号 `：` → `:`**，再走上面的
  结构化重排 —— 从聊天、日志里抄来的 `IN (81862，82929)`、`{“name”：“张三”}` 按一次
  「格式化」就能直接解析。只换这几枚符号，全角分号 / 括号不动（SQL 的冒号也不动：
  `:` 是命名参数与 `:=` 的语法字符）；**字符串与注释内部原样保留**，
  `'他说，你好'`、`"12：30"`、`-- 取组织树，只留有效` 这类内容不会被改
- 代码块高度自适应，超出后内部滚动，宽度跟随编辑区、窗口缩放不跑版

**笔记加密**
- 任意笔记可右键 →「设置加密口令…」；设好之后，这篇笔记的正文在数据库里**只留密文**：
  `content` 和 `plain`（搜索用的明文列）都写成空，翻数据库、搜关键词都看不到内容
- 切换笔记 = 立刻重新封上（内存里不留明文），切回来要口令；重开程序同样要口令
- **只有一种情况不用重新输入**：在加密笔记之间切换，且下一篇的口令与**当前这篇**相同
  —— 直接打开，不再询问。除此之外都要输入口令：从明文笔记切过来、重开程序、
  以及两篇口令不同（每篇 salt 不同，程序只能拿当前口令去解一次才知道是不是同一个）
- 口令只留在内存、退出即忘，不会写进数据库或任何文件
- 没解锁时：列表标题只露标题首字 + 一个星号（如「周\*」，互相能区分，泄漏量一个字符，
  这个字存在密文块里随密文走）；正文区显示「文字已加密」，工具栏置灰，编辑区上方
  一条提示条，点右侧「输入口令 →」即可解锁
  - 升级前就加密的老笔记没有存这个首字，第一次解锁后会补上；在那之前仍是「已加密笔记」
- 加密方式：PBKDF2-HMAC-SHA256（20 万次迭代，随机盐）派生密钥，再用 SHA-256 作伪随机函数的
  CTR 模式加密 + HMAC 认证——**先验签再解密**，密文改一个字节就打不开，全部只用标准库
- 口令本身不落盘，也没有「找回」：忘记口令等于内容永久丢失，这是设计取舍，不是缺陷

**整理与检索**
- 左栏分两组：**智能分类**（全部笔记 / 星标笔记 / 加密笔记，按条件筛出来的视图）与
  **文件夹**（工作、个人，以及你自己新建的），分组标题把它们隔开；智能分类不可删、不可当归属
- **跳到所属文件夹**：在全部 / 星标 / 加密视图，或**多级文件夹的父视图**里右键任意笔记，
  菜单里就有这一项，直接切到它真正所在的那个文件夹，路径上收着的各级自动展开、这条笔记
  被选中并滚到眼前。父视图的列表含整棵子树，翻到的笔记常常住在更深的子文件夹里，
  一层层往下找很烦，点一下就到（笔记就摆在当前文件夹时这一项不出现）
- **多级文件夹**：右键任意文件夹 →「新建子文件夹」，层级缩进 + 行首箭头收起 / 展开；
  最多 5 层。父文件夹的计数与视图都**包含子文件夹**里的笔记，搜索、移动同理
- **文件夹列底部不再堆按钮**：空白处右键 →「新建文件夹」（分组标题、列表下方留白都算空白）；
  重命名 / 删除 / 移动这些「得先指定某一项」的动作留在文件夹行自己的右键菜单里
- **收起 / 展开某一支有三种走法**：点行首箭头、双击文件夹行、右键 →「收起 / 展开子文件夹」，
  状态随窗口重开记住。点箭头只收放、不会顺手切换当前文件夹；列表滚到一半收放时，
  滚动位置也不回顶 —— 点中的那行原地不动，子行在它下面就地插入（只增删这一支的行，
  整列不重建，其它行不会跟着动）
- **文件夹图标随状态变**：展开 = 实心主题色前盖 + 探出的一角稿纸；收起 = 空心描边文件夹；
  没有子文件夹的叶子始终是空心。行首箭头是线条 chevron（收起 `>`、展开 `v`），
  占了 18×18 的可点区：常态只画箭头，鼠标停上来才浮出一层圆角底，指哪儿能点一目了然
  （叶子那一格留空、不画不变手形，名字才对得齐）
- **全部展开 / 全部收起**：「文件夹」分组标题右缘那两枚竖向双箭尖（朝外 = 摊开、
  朝内 = 收拢），一下把整列收起来或摊开，不用一层层点。这是整列级动作，所以摆在标题
  行而不是每行文件夹上；叶子文件夹不写收起标记（以后在它下面建子文件夹不会凭空不显示）
- **新建文件夹只插一行**：新行就地落在父支末尾（其它行不重建、不跳）；若在收起的
  文件夹里建子文件夹，父级会自动展开让新行露出来；新行在视口外时列表做最小幅度的
  滚动把它带进来
- 删除文件夹会连同它的子文件夹和里面的笔记一起删，确认框会写明波及范围
- 笔记可在文件夹之间拖拽移动；右键「移动笔记到…」弹出的是一棵**可收放的目标树**：
  层级缩进 + 引导线，箭头收放不相关的分支，右边标各自的笔记条数，双击或回车确认
- 星标、置顶，重要内容置顶显示
- 全文搜索即时过滤（走 SQLite FTS5 索引，环境不支持时自动回退 LIKE；搜索词里的 `%` `_` 按字面匹配），空结果有明确提示
- **搜索框住在文件夹列表顶部**：白底描边样式，宽度始终等于所在列宽减去左右留白；
  收起左侧两栏时它跟着整列一起收起（顶栏不留搜索残件），展开后回到原位置
- **顶栏就是窗口标题栏**：系统那条白色标题栏不再出现在界面上 —— 应用把客户区顶到窗口最上沿，
  阴影、圆角、任务栏按钮、Alt+Tab、贴边缩放都仍是系统原生的那一份。顶栏左侧是
  应用图标 + 「素笺」，一条竖分割线之后是折叠开关 + 齿轮（全局设置）+ 数据库（数据管理）
  + 圆圈 i（关于），再一条竖分割线，最右是记事本（新建笔记，唯一的**绿色**图标）；
  右侧只剩最小化 / 最大化 / 关闭三枚窗口键。两条竖线把顶栏断成三段：
  「我是谁」│「能干什么（看）」│「动手新建」，同宽同高同色的标点，不是边框。
  按住顶栏空白处拖动即可移动窗口（双击最大化 / 还原），拖动时窗口内容不重绘、跟着鼠标走
- **收起 / 展开左侧两栏只有顶栏一个入口**：就是第一条竖线右边那枚小图标（四根横杠 + 实心三角，
  取自 `icon/sz.svg`：原样＝收起、水平镜像＝展开）。它折叠后依然可见，悬浮提示会跟着
  变成「展开左侧两栏」。最左缘原来那条 22px 的折叠细条已经撤掉 —— 少一列，左栏直接贴到
  窗口左缘，收起后也不留那一条空白占位
- **全局设置收进了一枚齿轮**（`icon/setting.svg`，紧跟在折叠开关右边）：原来顶栏右侧那块
  写着「设置」的文字按钮不再占位，功能一样 —— 点它或按 `Ctrl + ,` 打开同一张
  全局设置（正文字体族 / 正文字号 + 预览）
- **新建笔记从文字按钮换成了图标**（`icon/create.png`，记事本 + 铅笔，单独排在第二条竖线右侧）：
  它原来是最右端那枚写着「新建笔记」的实心胶囊，压在这条 30px 高的图标带里最重、最占地方；
  换成图标后右侧整块让给窗口键。为了不淹没在一排灰图标里，它是运行时**染成强调色**的
  那一枚（位图颜色改不了，按 alpha 重新上色），`Ctrl + N` 照旧
- **数据管理单独立了一枚图标**（`icon/db.png`，数据库圆柱 + 齿轮，紧跟齿轮右侧）：导出备份 /
  导入数据 / 清空所有数据原来挤在设置弹窗下半部分，和外观项混在一起、想导出得先想到「设置」；
  现在一步直达，每一项都有独立说明（清空是不可撤销的，写清了会删掉什么）
- **「关于」也单独立了一枚图标**（`icon/about.png`，圆圈 + i，紧跟数据管理右侧）：应用图标与名字、
  版本号（`v1.0.0`，唯一来源是 `scripts/version.py`）、三行说明（「不注册 / 不上传」「数据在哪」
  「只有点检查更新时才联网」），下面是「项目与反馈」两条外链 —— `icon/github.png` 配
  项目地址、`icon/issue.png` 配问题反馈（`/issues`），图标运行时按 alpha 染成主题文字色。
  地址是**完整 URL、单行不折行**（弹窗宽度由最长的那串地址撑出来，本机 560×384），
  整行可点。底部是「检查更新」与「关闭」两枚按钮，检查结果就地显示在按钮上方那一行
  （不另开窗：关于窗本身是模态的，再叠一层弹窗会把 grab 一起带走）。发现新版后这枚
  按钮依次变成「下载更新」→「立即更新」，所有动作都落在同一个按钮上（这张窗的宽度是
  全项目的标尺，不新增控件）；下载中它变成「取消下载」，取消会保留断点、下次接着下。
  它原来压在设置弹窗最底下，得先打开设置再往下找；
  现在和导出/清空同一个逻辑 —— 属于「关于这个应用」的东西都在这排图标里
- **命中词在正文里标黄**：搜索时当前打开的这篇里，每个命中的关键词都会铺一层琥珀色底；
  改动关键词就跟着重标，把搜索框里的关键词删空，高亮立刻消失。黄底只存在于屏幕上，不会写进笔记

**数据与外观**
- 本地存储：SQLite 单文件数据库，旧版 JSON 数据首次启动自动迁移，不丢历史
- 一键导出备份（默认 `.json.gz`，可选明文 `.json`），导入支持「覆盖现有数据」或「合并追加」；
  备份带 schema 版本与校验和，合并按正文指纹去重（同一个备份导两次不会翻倍）
- 可读取 WorkBuddy 当前皮肤并自动适配配色，也可回退到内置浅灰配色
- **状态色按语义推导，不直接吃皮肤给的值**：悬停＝所在底色暗一档（只动明度、保住色相），
  选中＝所在底色 + 主题色，浮层＝稿纸 + 一层主题色再压到与稿纸反差达标。
  换主题、换深浅都自动成立，也不会再出现「悬停和选中同色」这类撞色
- 细节打磨：圆角自绘 UI、鼠标滚轮流畅浏览、长标题悬停跑马灯、中文界面优先字体

## 快捷键

不用离开键盘就能完成全部高频操作：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + N` | 新建笔记 |
| `Ctrl + S` | 立即保存（平时停顿 0.6 秒会自动存，这个键只是让你安心） |
| `Ctrl + ,` | 打开全局设置 |
| `Ctrl + B` / `Ctrl + I` / `Ctrl + U` | 加粗 / 斜体 / 下划线 |
| `Ctrl + Shift + S` | 删除线 |
| `Ctrl + E` | 行内代码（先选中文字） |
| `Ctrl + 1` / `Ctrl + 2` / `Ctrl + 0` | 一级标题 / 二级标题 / 回到正文（作用于光标所在行，不用先选中；第一行恒为标题，不受影响） |
| `Ctrl + Shift + K` | 插入代码块 |
| `Ctrl + Shift + -` | 插入分割线 |
| `Ctrl + Shift + T` | 插入待办项 |
| `Ctrl + K` | 插入 / 编辑超链接：选中文字 → 填地址；光标停在链接里 → 改文字和地址；选中已有链接 → 取消 |
| `Ctrl + D` | 复制整行：光标所在行（含加粗、标题、引用、待办勾选状态）整行复制一份插到下面 |
| `Ctrl + Y` | 删除整行：光标所在行整行删掉；拖选了几行就删这几行 |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做（`Ctrl + Y` 原本挂在重做上，让给了更高频的删除整行） |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | 下一个 / 上一个标签页（`Ctrl + PageDown` / `Ctrl + PageUp` 同） |
| `Ctrl + W` | 关闭当前标签页（标签上的 ×、中键单击同效；右键还能「关闭其它」） |

**markdown 快捷输入**

段首敲下面这些，再敲一个空格（`---` 是敲完回车；最后三条不限行首），格式当场生效：

| 敲这个 | 变成 |
| --- | --- |
| `#` + 空格 | 一级标题 |
| `##` + 空格 | 二级标题 |
| `-` + 空格（`*` / `+` 同） | 项目符号（右移两格） |
| `->` + 空格 | 三角列表（右移两格；`-` 后面紧跟 `>`，不会被项目符号抢走） |
| `-[]` + 空格 | 待办勾选框（右移两格，后面接着写正文即可；勾选态点框切换） |
| `1.` + 空格 | 有序列表（右移两格，回车自动递增） |
| `>` + 空格 | 引用块（文字缩进两格；回车续接，空引用行再回车跳出） |
| 三个反引号 + 空格，或三个反引号 + 语言名 + 回车 | 代码块 |
| `---` + 回车 | 分割线 |
| `[文字](网址)` + 空格 | 超链接（括号和网址收起，文字变蓝） |
| `@` + 空格 | 关联笔记（浮出候选，↑↓ Enter 选择，插入蓝色的 `@标题`，单击跳转） |
| `date()` + 空格 | 当前日期 `2026-10-23` |
| `datetime()` + 空格 | 当前时间 `2026-10-23 19:13:05` |
| `$5+6=` + 空格 | 公式计算 → `5+6= 11`（`$` 是触发键，算完就删掉；见下条说明） |

> 除超链接、时间函数和 `$` 公式外，其余几条都只认行首，正文中间打这些符号不受影响；`###` 及以上不转换（程序只有两级标题）。
> 首行是标题行，列表类的四种前缀在那里不生效（`-[] ` 也是 —— `-` 后面必须紧跟 `[]` 和空格，
> 写成 `- [ ]` 的话 `- ` 会先被项目符号认领）。
> 超链接和时间函数不限行首，但只有「刚敲完的那一处」才展开——回头再编辑这几行，它们不会自己变。
> 列表的「两格缩进」只对新敲的列表生效 —— 旧笔记里已有的列表行保持原样，
> 只有在你编辑到那一行、回车续接之后才会变成新形态。
>
> 项目符号的字形是 `●`（U+25CF）。上一版用的 `•` 在 12 号字下只有 5×4 像素，比汉字小一大截，
> 看着像句号；载入老笔记时会把行首的 `•` 换成 `●`（一换一、等长，正文长度不变）。
>
> 待办勾选框现在是正文里的一个字符（⬜ 未勾 / ✅ 已勾）。老笔记里的勾选框是浮在文字上的控件，
> 重开时自动转成字符形态（老的 ☐ / ⚪ / ▢ / ☑ 也会顺带换成新字形），勾选状态、颜色、加粗等样式都原样保留。
> 早期待办贴着左边（没有那两格缩进），载入时会补上，与项目符号 / 三角 / 序号对齐。
>
> `Ctrl + N` / `Ctrl + S` / `Ctrl + ,` / `Ctrl + Tab` / `Ctrl + W` 是全局的，焦点在列表或侧栏时同样有效；
> 其余快捷键作用于正文，光标在编辑器里才生效。
>
> 记不住也没关系：内置的「欢迎使用素笺」里就有一份同样的表，随时点开就能看。

## 快速开始

无需安装任何依赖，电脑上有 Python 3 即可运行：

```bash
python scripts/notes_app.py
```

启动后会在项目根目录的 `data/` 下自动创建 `notes_data.db` 数据库文件。

> 项目图标即仓库中的 [`icon/app_icon.png`](icon/app_icon.png)，同时作为应用窗口 / 任务栏图标（由 `scripts/notes_app.py` 启动时加载）。

### 运行测试（可选）

数据层、文本规则和加密都不依赖界面，用标准库 unittest 即可验证（SQLite 读写、搜索通配转义、
备份的编码解码与合并去重、markdown 前缀识别、口令与密文完整性、导出与 SQL 格式化的输出等）：

```bash
python -m unittest discover -s tests
```

也可以单独跑某一个文件，例如 `python tests/test_store.py`。

### 打包成 exe（可选）

`target/` 目录下已备好打包脚本，无需手写命令：

- 双击 `target/build.bat`（或命令行 `python target/build.py`）→ 自动安装 PyInstaller / Pillow 并打包
- 产物在 `target/dist/素笺/素笺.exe`，**双击即可打开，目标机器无需再装 Python**
- 数据库生成在 exe 旁的 `data/` 目录，整目录拷贝即可带着数据走、方便备份
- 只想从源码调试运行，可双击 `target/run.bat`（等同于 `python scripts\notes_app.py`）

## 数据说明

| 项目 | 说明 |
|---|---|
| 存储方式 | 本地 SQLite（`data/notes_data.db`），单文件、易备份 |
| 历史迁移 | 首次运行若检测到旧版 JSON 数据文件（含程序目录下的旧库），自动迁进 `data/` |
| 导出单篇笔记 | 工具栏「⋯」→ 纯文本 / Markdown / PDF。文本两种是 UTF-8（txt 带 BOM，记事本直接开）；PDF 走系统 GDI 排版成图再拼 PDF，**没有文字层**（不可选中/检索），零依赖、字形与界面一致 |
| 导出备份 | 数据库图标（数据管理）→「导出备份」→ 生成带时间戳的 `.json.gz`（默认）或 `.json`。内容为文件夹 / 笔记 / 外观偏好；正文按「文本 + 标签区间」存（不是逐字符），整体通常只有旧版的 1/10 |
| 导入数据 | 数据库图标（数据管理）→「导入数据」→ 可选覆盖或合并。覆盖会连外观（字号 / 字体 / 工具栏）一起恢复；合并只追加本机没有的笔记，并按正文指纹去重；老版 v1 备份照样能导 |
| 保存失败兜底 | 写库失败时会弹窗提示一次，并把内存数据另存为 `data/pending_<时间>.json`；下次启动提示，可用「导入数据」恢复 |
| 笔记加密 | 口令由你自己设。加密后的笔记在库里只存密文，`content` 与搜索用明文列均为空；口令不落盘、无法找回 |
| 笔记内链 | `@` 关联存在笔记的 `links` 里，地址是 `note:<笔记id>`、显示文字是 `@标题`。目标笔记改名 / 挪文件夹不断链；被删后点击提示「已不存在」。随导出备份一起走（外链与内链同一张表） |
| 多开保护 | 同一时间只允许运行一个窗口——两个实例会同时改写同一个库，容易互相覆盖 |
| 检查更新 | 「关于」→「检查更新」：读 GitHub Releases 的最新 tag 与本机版本比大小，版本号按数字逐段比较（`1.10` 比 `1.9` 新），解析不出来宁可漏报也不误报 |
| 自动更新 | 发现新版后同一枚按钮变成「下载更新」：**后台**下载 zip（支持断点续传、可随时取消，进度就地显示），下完比对 GitHub 给的 sha256，通过后解包并校验包里确有 `素笺.exe`，再点「立即更新」——程序退出、由一段批处理覆盖文件、然后自动重开。<br>替换**只覆盖程序文件**：`robocopy /E`（不是镜像）+ `/XD <安装目录>\data`，所以 `data/` 里一个字节都不会动；你随手放在安装目录里的其它文件也不会被删。替换前还会把整库导一份到 `data/updates/pre-v<版本>-<时间>.json.gz`（留最近 3 份），万一新版把迁移写坏了能用「导入数据」捞回来。<br>安装包落在 `%LOCALAPPDATA%\Sujian\update\`，不放程序目录（程序可能装在 `Program Files`，那里没写权限）。替换失败时批处理留一行 `update_error.log`，下次启动会提示，不会「点了更新、重启、还是老版本，也没人说为什么」 |
| 网络访问 | 无账号、无同步、无遥测。平时不联网 —— 只有手动点「检查更新 / 下载更新」时才访问 GitHub，请求头里只有应用名和版本号（GitHub 强制要求 UA），不带设备标识、不带笔记内容。**没有启动自动检查**，也永远不会替你下载你没点过的版本 |

│   ├── mention_ui.py     # @ 候选浮层：自绘列表（不抢焦点，打字过滤不受影响）

源码运行读「项目根 `data/`」，打包成 exe 后读「exe 旁 `data/`」，数据始终随程序带得走。

依赖方向是单向的：`store` ← `theme` ← `widgets` ← `app_ui` / `app_actions` ← `notes_app`。

## 技术栈

- **语言**：Python 3
- **GUI**：Tkinter（标准库，零外部依赖）
- **数据**：SQLite3（标准库），全文检索用 FTS5 + trigram 分词（环境不支持时自动回退 LIKE）
- **分层**：`store`（数据）→ `theme`（配色）→ `widgets`（控件）→ `app_ui` / `app_actions`（界面 / 动作）→ `notes_app`（入口），全部只需标准库
- **加密**：PBKDF2-HMAC-SHA256 派生密钥 + HMAC 认证的 CTR 加密，同样只用标准库（`hashlib` / `hmac` / `secrets`）
- **测试**：`tests/`，标准库 unittest（`python -m unittest discover -s tests`），无第三方依赖

## 关于 PDF 导出

零依赖是硬约束，而 PDF 里要让中文像样只有两条路：

1. **嵌 TrueType 子集** —— 得自己实现 `glyf / loca / cmap / hmtx` 的子集化；不做子集就得把
   整套 10MB 的雅黑塞进每一份导出，一条便签变成 13MB 的 PDF。
2. **先把字画成图，再把图画进 PDF** —— GDI 是系统自带的（`ctypes` 直接调，不算第三方），
   字体、字号、行距用的就是屏幕上那一套。

这里走第 2 条：`ctypes` 调 `gdi32` 在内存 DIB 上排一遍版（H1 1.35 倍 / H2 1.15 倍、行高 1.7、
中文折行带行首禁则、列表与待办画几何图形而不是字符），144dpi 出 A4 位图，`zlib` 压缩后按
PDF 的图片 XObject 逐页拼装（`build_pdf()` 是纯函数，脱离 Windows 也能单测）。

代价：**PDF 里没有文字层**，复制和全文检索取不到字；换来的是零依赖、字形与界面一致、
一页约 100–300KB。要文字可选，只能接受引入字库子集化或第三方库。

## 适用人群

适合想要一个「像系统自带笔记一样简单，但数据完全自主」的轻量笔记工具的用户；也适合作为 Python Tkinter 桌面应用的学习参考项目。
