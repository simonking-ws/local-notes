# local-notes

> 复刻 macOS 备忘录的本地桌面笔记应用 —— Python + Tkinter 编写，零第三方依赖，无需联网，数据只存在你自己的电脑上。

## 项目介绍

local-notes 是一个致敬 macOS 备忘录（Apple Notes）的桌面笔记程序。它采用经典的三栏布局：顶部工具栏、左侧文件夹与备忘录列表、右侧富文本编辑器，整体风格简洁克制，专注于「打开就能写」的流畅体验。

与大多数笔记软件不同，local-notes 不依赖任何第三方库，也不连接任何云端服务——只需要电脑上自带 Python 即可运行。所有文件夹、备忘录和设置都保存在本地的 SQLite 数据库中，配合一键 JSON 导出备份，数据的所有权完全归你所有。

## 功能特性

- **三栏式布局**：工具栏 / 文件夹+备忘录列表 / 编辑器，还原 macOS 备忘录的交互逻辑
- **文件夹管理**：自定义文件夹整理笔记，内置「全部备忘录」「星标备忘录」智能文件夹
- **富文本编辑**：支持标题、加粗、斜体与待办清单（checkbox），满足日常记录与任务管理
- **星标与搜索**：重要笔记一键星标，全文搜索即时过滤，空结果有明确提示
- **本地数据存储**：SQLite 单文件数据库，旧版 JSON 数据首次启动自动迁移，不丢历史
- **一键导出备份**：文件夹 + 备忘录 + 设置可随时导出为 JSON 文件
- **全局字号设置**：正文字号可调，全局生效并持久保存
- **细节打磨**：长文件名悬停跑马灯滚动、圆角自绘 UI、鼠标滚轮流畅浏览、中文界面优先字体适配

## 快速开始

无需安装任何依赖，Python 3 即可运行：

```bash
python notes_app.py
```

启动后会自动在同目录创建 `notes_data.db` 数据库文件。

## 数据说明

| 项目 | 说明 |
|---|---|
| 存储方式 | 本地 SQLite（`notes_data.db`），单文件、易备份 |
| 历史迁移 | 首次运行若检测到旧版 `notes_data.json`，自动导入数据库 |
| 导出备份 | 工具栏「导出」→ 生成带时间戳的 JSON 备份文件 |
| 网络访问 | 完全不联网，无账号、无同步、无遥测 |

## 技术栈

- **语言**：Python 3
- **GUI**：Tkinter（标准库，零外部依赖）
- **数据**：SQLite3（标准库）
- **单文件实现**：全部逻辑位于 `notes_app.py`，便于阅读与二次开发

## 适用场景

适合想要一个「像系统自带备忘录一样简单，但数据完全自主」的轻量笔记工具的用户；也适合作为 Python Tkinter 桌面应用的学习参考项目。
