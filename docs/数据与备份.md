# 数据与备份

素笺的正文、文件夹、外观偏好全部落在本地一个 SQLite 文件里，不上传、不同步。

## 数据在哪

| 项目 | 说明 |
|---|---|
| 存储方式 | 本地 SQLite（`data/notes_data.db`），单文件、易备份 |
| 源码运行 | 读「项目根 `data/`」 |
| 打包运行 | 读「exe 旁 `data/`」—— 整目录拷贝即可带着数据走 |
| 历史迁移 | 首次运行若检测到旧版 JSON 数据文件（含程序目录下的旧库），自动迁进 `data/` |
| 多开保护 | 同一时间只允许运行一个窗口 —— 两个实例会同时改写同一个库，容易互相覆盖 |

## 单篇导出

工具栏「⋯」→ 纯文本 / Markdown / PDF，文件名默认取笔记标题：

- 文本两种是 UTF-8（`.txt` 带 BOM，记事本直接开）。
- PDF 走系统 GDI 排版成图再拼 PDF，**没有文字层**（不可选中 / 检索），零依赖、字形与界面一致。原理见 [开发与打包 · 关于 PDF 导出](开发与打包.md#关于-pdf-导出)。

## 整库备份与恢复

入口都在顶栏的「数据管理」（数据库图标）里。

| 动作 | 说明 |
|---|---|
| 导出备份 | 生成带时间戳的 `.json.gz`（默认）或 `.json`。内容为文件夹 / 笔记 / 外观偏好；正文按「文本 + 标签区间」存（不是逐字符），体积通常只有旧版格式的 1/10 |
| 导入数据 | 可选「覆盖现有数据」或「合并追加」。覆盖会连外观（字号 / 字体 / 工具栏）一起恢复；合并只追加本机没有的笔记，按正文指纹去重（同一个备份导两次不会翻倍）；老版 v1 备份照样能导 |
| 清空所有数据 | 不可撤销，确认框会写清会删掉什么 |

## 保存失败兜底

写库失败时会弹窗提示一次，并把内存数据另存为 `data/pending_<时间>.json`；下次启动会提示这份快照的存在，可用「导入数据」恢复。文件本身保留不动，不会自动删除。

数据库被占用（多开、杀软扫描、云盘同步锁）时最多等 2 秒，超时就报错交给界面提示 —— 不用 SQLite 默认的 5 秒，那段时间界面线程是冻住的，用户只会以为程序卡死。

## 加密笔记的数据形态

| 项目 | 说明 |
|---|---|
| 落库形态 | 正文只存密文；`content` 与搜索用明文列均为空 |
| 口令 | 由你自己设，只留在内存、退出即忘；不落盘，也无法找回 |
| 算法 | PBKDF2-HMAC-SHA256（20 万次迭代 + 随机盐）派生密钥，SHA-256 作 PRF 的 CTR 加密 + HMAC 认证，先验签再解密 |

细节见 [使用指南 · 笔记加密](使用指南.md#6-笔记加密)。

## 笔记内链

`@` 关联存在笔记的 `links` 里，地址是 `note:<笔记id>`、显示文字是 `@标题`。目标笔记改名 / 挪文件夹不断链；被删后点击提示「已不存在」。随导出备份一起走（外链与内链同一张表）。

## 检查更新与自动更新

入口：「关于」→「检查更新」。

- **检查**：读 GitHub Releases 的最新 tag 与本机版本比大小，版本号按数字逐段比较（`1.10` 比 `1.9` 新），解析不出来宁可漏报也不误报。
- **下载**：发现新版后同一枚按钮变成「下载更新」，**后台**下载 zip（支持断点续传、可随时取消，进度就地显示），下完比对 GitHub 给的 sha256，通过后解包并校验包里确有 `素笺.exe`。
- **安装**：再点「立即更新」—— 程序退出、由一段批处理覆盖文件、然后自动重开。
  - 替换**只覆盖程序文件**：`robocopy /E`（不是镜像）+ `/XD <安装目录>\data`，所以 `data/` 里一个字节都不会动；你随手放在安装目录里的其它文件也不会被删。
  - 替换前还会把整库导一份到 `data/updates/pre-v<版本>-<时间>.json.gz`（留最近 3 份），万一新版把迁移写坏了能用「导入数据」捞回来。
  - 安装包落在 `%LOCALAPPDATA%\Sujian\update\`，不放程序目录（程序可能装在 `Program Files`，那里没写权限）。
  - 替换失败时批处理留一行 `update_error.log`，下次启动会提示。

## 网络访问

无账号、无同步、无遥测。平时不联网 —— 只有手动点「检查更新 / 下载更新」时才访问 GitHub，请求头里只有应用名和版本号（GitHub 强制要求 UA），不带设备标识、不带笔记内容。**没有启动自动检查**，也永远不会替你下载你没点过的版本。
