# 快捷键

不用离开键盘就能完成全部高频操作。内置的「欢迎使用素笺」里也有一份同样的表，随时点开就能看 —— 两边的分组与顺序保持一致，改一处就要改另一处。

## 文件

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + N` | 新建笔记 |
| `Ctrl + S` | 立即保存（平时停顿 0.6 秒会自动存，这个键只是让你安心） |
| `Ctrl + ,` | 打开全局设置 |

## 格式

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + B` / `Ctrl + I` / `Ctrl + U` | 加粗 / 斜体 / 下划线 |
| `Ctrl + Shift + S` | 删除线 |
| `Ctrl + E` | 行内代码（先选中文字） |
| `Ctrl + 1` / `Ctrl + 2` / `Ctrl + 0` | 一级标题 / 二级标题 / 回到正文（作用于光标所在行，不用先选中；第一行恒为标题，不受影响） |

## 插入

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Shift + K` | 插入代码块 |
| `Ctrl + Shift + T` | 插入待办项 |
| `Ctrl + Shift + -` | 插入分割线 |
| `Ctrl + K` | 插入 / 编辑超链接：选中文字 → 填地址；光标停在链接里 → 改文字和地址；选中已有链接 → 取消 |

## 编辑与查找

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做（`Ctrl + Y` 原本挂在重做上，让给了更高频的删除整行） |
| `Ctrl + D` | 复制整行：光标所在行（含加粗、标题、引用、待办勾选状态）整行复制一份插到下面 |
| `Ctrl + Y` | 删除整行：光标所在行整行删掉；拖选了几行就删这几行 |
| `Ctrl + F` | 本篇内查找：浮出查找框，输入即高亮；`Enter` / `Shift + Enter` 上下条，`Esc` 关闭 |
| `Ctrl + H` | 查找替换：同一张浮条展开第二行；`Enter` 替换当前并跳下一条，`Ctrl + Enter` 全部替换 |
| `Ctrl + Shift + D` | 涂鸦标注：进入 / 退出。进入后整个窗口被蒙层罩住（顶栏、侧栏、正文都不能操作），浮出的工具条（可按住拖动）能画线、箭头、形状与编号标记；`Esc` 也能退出，**所有涂鸦都不保存** |

## 标签页

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | 下一个 / 上一个标签页（`Ctrl + PageDown` / `Ctrl + PageUp` 同） |
| `Ctrl + W` | 关闭当前标签页（标签上的 ×、中键单击同效；右键还能「关闭其它」/「关闭所有」） |

> 多标签页默认开着，可在「全局设置 → 标签页」里关掉；关掉后标签条消失，这一节的两条快捷键也一并停用（正文内容不受影响）。

## markdown 快捷输入

段首敲下面这些，再敲一个空格（`---` 是敲完回车；最后几条不限行首），格式当场生效：

| 敲这个 | 变成 |
| --- | --- |
| `#` + 空格 | 一级标题 |
| `##` + 空格 | 二级标题 |
| `-` + 空格（`*` / `+` 同） | 项目符号（右移两格） |
| `->` + 空格 | 三角列表（右移两格；`-` 后面紧跟 `>`，不会被项目符号抢走） |
| `-[]` + 空格 | 待办勾选框（右移两格，后面接着写正文即可；勾选态点框切换） |
| `1.` + 空格 | 有序列表（右移两格，回车自动递增） |
| `>` + 空格 | 引用块（文字缩进两格；回车续接，空引用行再回车跳出） |
| 三个反引号 + 空格，或三个反引号 + 语言名 + 回车 | 代码块 |
| `---` + 回车 | 分割线 |
| `[文字](网址)` + 空格 | 超链接（括号和网址收起，文字变蓝） |
| `@` + 空格 | 关联笔记（行首、标点后、紧贴文字都认；面板顶部有搜索框，弹出即聚焦，输入即过滤；候选列出全部笔记，滚轮 / 右侧滚动条翻看，↑↓ / Enter 选择，插入蓝色的 `@标题`，单击跳转） |
| `date()` + 空格 | 当前日期 `2026-10-23` |
| `datetime()` + 空格 | 当前时间 `2026-10-23 19:13:05` |
| `$5+6=` + 空格 | 公式计算 → `5+6= 11`（`$` 是触发键，算完就删掉） |

### 规则说明

- 除超链接、时间函数和 `$` 公式外，其余几条都只认行首，正文中间打这些符号不受影响；`###` 及以上不转换（程序只有两级标题）。
- 首行是标题行，列表类的四种前缀在那里不生效（`-[] ` 也是 —— `-` 后面必须紧跟 `[]` 和空格，写成 `- [ ]` 的话 `- ` 会先被项目符号认领）。
- 超链接和时间函数不限行首，但只有「刚敲完的那一处」才展开 —— 回头再编辑这几行，它们不会自己变。
- 列表的「两格缩进」只对新敲的列表生效 —— 旧笔记里已有的列表行保持原样，只有在你编辑到那一行、回车续接之后才会变成新形态。
- 工具栏的四个列表按钮是**开关**：光标行（或选中的每一行）已经是同一种列表时，再点一次就是清除标记；否则统一转成该类型 —— 选中多行可以一次批量互转，标题行永远跳过。右键这四个按钮会弹出「项目符号 / 有序列表 / 三角列表 / 待办事项 / 重新编号 / 清除列表标记」。
- 有序列表会**自动重编号** —— 回车续接、删除整行（`Ctrl+Y`）、复制整行（`Ctrl+D`）或 markdown `1. ` 转换之后，同一缩进层级的连续块都会重排成 1、2、3…；更深的子列表跳过但不打断父级编号，子列表自己单独编号。
- 项目符号的字形是 `●`（U+25CF）。上一版用的 `•` 在 12 号字下只有 5×4 像素，比汉字小一大截，看着像句号；载入老笔记时会把行首的 `•` 换成 `●`（一换一、等长，正文长度不变）。
- 待办勾选框现在是正文里的一个字符（⬜ 未勾 / ✅ 已勾）。老笔记里的勾选框是浮在文字上的控件，重开时自动转成字符形态（老的 ☐ / ⚪ / ▢ / ☑ 也会顺带换成新字形），勾选状态、颜色、加粗等样式都原样保留；早期待办贴着左边（没有那两格缩进），载入时会补上。

## 作用范围

`Ctrl + N` / `Ctrl + S` / `Ctrl + ,` / `Ctrl + Tab` / `Ctrl + W` / `Ctrl + Shift + D` 是全局的，焦点在列表或侧栏时同样有效；其余快捷键作用于正文，光标在编辑器里才生效。涂鸦标注打开时，除 `Ctrl + Shift + D` 外的全局快捷键一律暂时停用，避免正文在蒙层底下被换掉。
