## 常见问题速查

- **数据存在哪？** 源码运行时是项目根的 `data/notes_data.db`，打包后是 exe 旁的 `data/notes_data.db`。
- **换电脑怎么搬？** 拷贝整个 `data/`，或用「数据管理 → 导出备份」再在新机器「导入数据」。
- **忘了加密口令怎么办？** 没有找回途径，内容无法恢复 —— 口令不落盘是设计取舍。
- **程序关着的时候会提醒吗？** 不会；错过的提醒超过 10 分钟也不再补弹。
- **PDF 为什么复制不出文字？** 导出走的是「排版成图再拼 PDF」，没有文字层，换来的是零依赖。
- **会不会偷偷联网？** 只有你手动点「检查更新 / 下载更新」时才访问 GitHub，不带任何笔记内容与设备标识。
